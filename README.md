# 🧩 LogicDominoes (Quantifier Logic Game)

An interactive web-based educational game developed with **HTML5**, **CSS3**, and **Vanilla JavaScript**. Designed for formal logic students to learn about quantifiers ($\forall x$, $\exists x$), categorical propositions, and logical equivalences through classic domino mechanics.

## ✨ Features
- **Drag and Drop Mechanics:** Smooth native HTML5 drag-and-drop system to build the logic chain on the board.
- **Bilingual Support (ES / EN):** Instant toggle button to switch all interface texts, rules, and domino tile translations between Spanish and English.
- **Dynamic Vector Connections:** Automatically calculates coordinates to render directional SVG arrows connecting adjacent tiles.
- **Mathematical Validation:** Automatically verifies the logical sequence of the chain when all tiles are placed.
- **Retro Aesthetic Design:** Styled with a responsive layout and custom background atmosphere.

## 🛠️ Technologies Used
- **HTML5** (Semantic structure)
- **CSS3** (Flexbox, custom styling, responsive layout)
- **JavaScript (ES6+)** (Game state, random tile generation, DOM manipulation, SVG line rendering)

## 📖 How to Play
1. Review the randomized tiles available in your hand ("Tu Mano").
2. Drag and drop tiles onto the central board ("Tablero") to build a continuous chain.
3. Ensure the right side of a tile logically matches the left side of the next tile (following equivalence rules like De Morgan's Laws).
4. Once all tiles are placed, the system will validate your logic sequence!
